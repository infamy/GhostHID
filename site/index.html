GhostHID

A thumb-sized USB stick that becomes a real keyboard and mouse for any computer — driven from your phone, your browser, or your desktop's screen edge.

Plug it into the target. Control it over Wi-Fi. There is nothing to install on the machine you're controlling — to its USB port, GhostHID simply is a keyboard and mouse.

Flash it in your browser How it works →

To USB, it's real hardware. Everything else is the network.

GhostHID runs on a ~$10 ESP32-S3 board that plugs straight into a USB-A port and enumerates as a composite keyboard + mouse. The target can't tell it from a real one, because at the USB layer it is one.

Everything else happens over Wi-Fi. Open its web app for hands-on control from a phone or laptop — or point an existing Deskflow / Barrier / Input Leap layout at it and slide your pointer onto the target like it's just another screen. No agent, no driver, nothing installed on the machine you're driving.

What it does

One stick, a lot of reach.

Built for the moments you can't — or shouldn't — install anything on the target: a headless box, a locked-down machine, a KVM, a friend's PC, the podium laptop.

01

Control from any browser

A phone-friendly web app: live typing, every key and combo, a trackpad, sticky modifiers. No app to install on either end.

02

Your desktop's edge

Join a Deskflow / Barrier / Input Leap layout as a screen and move your pointer straight onto the target. Nothing runs on the target.

03

It talks back

Reads the host's lock-LED reports — Caps / Num / Scroll — plus a "the target is really driving me" signal, shown on the screen and in the web UI.

04

Presenter mode

Next / back / black-screen with two timers — total talk and per-slide — like a hardware clicker, from your phone. Presets for Slides, Keynote, PowerPoint.

05

Media & system keys

Volume, mute, play/pause, next/prev, brightness — plus sleep, wake and power, as a full consumer-control collection.

06

On-device screen

A 1.47" LCD shows a Wi-Fi join QR, the IP and live status; an RGB LED reads its state across the room.

And under the hood: mutual-TLS screen sessions with a pinned server cert · one-click config export to clone a fleet of boards · browser OTA updates · a generic USB keyboard ID so it doesn't trip endpoint security · release-everything-on-disconnect safety.

The hardware

A USB-A stick you can print a home for.

It runs on the Waveshare ESP32-S3-LCD-1.47 — dual-core, native USB, a colour screen and an RGB LED, in a board the size of a chunky flash drive. The repo ships a parametric case with the ghost as a two-colour inlay.

  • Plugs in directly. Integrated USB-A plug — no cable, no dongle.
  • Dual-core headroom. The screen session and the web server never fight for the radio.
  • Printable case. OpenSCAD + STL + a ready-to-slice 3MF, exact-fit to the board's drawing.
  • Yours to change. MIT-licensed firmware, web UI and hardware, all in one repo.
The shape of it

Layered so it stays honest.

Each layer knows only its neighbour. The network never touches USB; the HID layer never learns where a command came from — so a stuck key is impossible by construction.

Phone / browser / Deskflow

A keystroke or a pointer move, as JSON or the Synergy protocol.

CommandProcessor

Validates, rate-limits, authenticates. The only place policy lives.

HidDevice → USB

The one layer that speaks USB. Holds the state that "release everything" undoes.
