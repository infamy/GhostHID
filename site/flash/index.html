GhostHID firmware flasher

Flash the board straight from this page. No drivers, no toolchain.

Your browser can't flash over USB. Use desktop Chrome or Edge (Web Serial isn't available in Firefox, Safari, or on mobile).
For the one supported board, the Waveshare ESP32-S3-LCD-1.47. It verifies the chip before flashing.

Before you click Install

  1. Use a data USB-C/USB cable (not charge-only) into the board's native USB port.
  2. Put the board in download mode: hold BOOT, tap RST, release BOOT. (If the board has only a BOOT button, hold it while plugging the cable in.)
  3. Click Install above and pick the serial port in the dialog.
  4. When it finishes, tap RST once to run GhostHID.

A fresh flash erases stored settings (Wi-Fi, token). That's expected for a new device.

After flashing

  1. The board raises its own Wi-Fi AP: GhostHID-XXXX (default password ghosthid-setup).
  2. On the S3-LCD board, the screen shows a QR code. Scan it with your phone camera to join the AP.
  3. Join the AP and open http://192.168.4.1/ to set your Wi-Fi, token, and KVM options.

Change the AP password and pairing token before putting it on a shared network.
